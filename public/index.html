ページの表示はできていますが、投稿の保存先（Supabase）につながっていません。 下の3つを済ませると、投稿とコメントが使えるようになります。

  1. Supabase でプロジェクトを作る
  2. SQL Editor で supabase/schema.sql を実行する
  3. Project Settings → API の Project URL と anon public キーを public/config.js に書く（または GitHub の Secrets に登録する）。 URL は https://xxxx.supabase.co の形です。 /rest/v1 などが付いた別の URL と間違えないでください

詳しい手順は README.md にあります。
