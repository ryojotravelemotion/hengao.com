このサイトは Supabase をデータの置き場所として使います。まだ接続先が設定されていません。

  1. Supabase でプロジェクトを作る
  2. SQL Editor で supabase/schema.sql を実行する
  3. Project Settings → API の Project URL と anon public キーを public/config.js に書く（または GitHub の Secrets に登録する）

詳しい手順は README.md にあります。
